# GitHub profile · version 2

This replaces the original control-room artwork with a deliberately different **kinetic builder** style: bold typography, warm cream + acid lime, and a little illustrated robot **with individually animated limbs and app components**.

## Install

1. Open `https://github.com/Albert534/Albert534`. If it does not exist, create a public repository with that exact name.
2. Copy `README.md` to the repository root.
3. Copy the **entire** `assets/` folder into the repository root.
4. Commit and push. Reload `https://github.com/Albert534`.

Both the animated GIF and SVG are stored locally in the repository. No external image hosts, no fake GitHub statistics, no fictional portfolio projects, no JavaScript required.

## Contents

```
Albert534/
├── README.md
└── assets/
    ├── hero-builder.gif     # true frame-by-frame animation
    ├── hero-still.png      # alternative static banner
    └── manifesto.svg       # graphic typography strip
```

To disable motion, change `hero-builder.gif` to `hero-still.png` in the opening image in the README.

You can change the contact email or remove the Contact link without changing any graphics. No business or personal contact information is included by default.
