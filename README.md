## Hey, I'm Aung.

I build web apps and the systems behind them. Some days that's working on a UI; other days it's tracking down an API issue, fixing a database query, or figuring out why something behaves differently after deployment. I like knowing how the pieces fit together.

I work mostly with **React, Next.js, Node.js, and PostgreSQL**, alongside **Redis, Docker, and Linux**. I'm also spending more time with **Python automation**, learning **Flutter**, and exploring where **AI** can actually be useful in software people use.

I enjoy the entire process, from the first rough idea to the part where it's running and somebody depends on it.
